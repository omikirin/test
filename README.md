# Romance Simulation Demo

This repository contains a very simple web-based romance simulation example.

## Files

- `index.html`: Unity WebGL loader (from the original project)
- `romance.html`: Basic web page for the text-based romance simulation.
- `romance.js`: JavaScript that handles user interaction and simple conversation logic.

## Running

Open `romance.html` in a web browser. Enter a character name, then select options or type messages to interact. Each choice affects the affection level displayed on the page.

## 遊び方 (日本語)

1. `romance.html` をブラウザで開きます。
2. キャラクター名を入力して **Start** ボタンを押します。
3. 表示される選択肢をクリックするか、メッセージ欄に入力して送信します。
4. 選んだ内容によって好感度が変化し、ページ上に表示されます。
